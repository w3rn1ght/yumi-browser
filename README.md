# Yumi Browser (iOS 12)

Браузер под джейлбрейкнутый iOS 12. Сделан под аниме-сайты и онлайн-кинотеатры
с HLS/mp4-плеерами: находит поток, который использует плеер на странице, и играет
его **нативно** в AVPlayer — с нужными `Referer`, `Origin`, `User-Agent` и cookies.

## Что умеет

- Вкладки, адресная строка, поиск (Яндекс, Bing или DuckDuckGo — выбор в настройках), кнопки назад/вперёд/домой, прогресс загрузки.
- **Инкогнито** (меню → Инкогнито): отдельное непостоянное хранилище WebKit, без cookies/кэша/истории на диске; память просмотра в этом режиме не сохраняется.
- Стартовая страница с логотипом и своими сайтами: встроенные ссылки убраны, сайты
  добавляются кнопкой **+ Добавить сайт** и хранятся в приложении (крестик на карточке — удалить).
- Сохранение сессии: после перезапуска вкладки открываются заново.
- Persistent cookies — логин на сайтах не слетает.
- User-Agent: мобильный Safari 12 / полный macOS Safari / своя строка.
  Режим «полная версия» переключается отдельно для каждого сайта (меню → Полная версия).
- Перехват `m3u8` / `mp4` / `mpd`: из `fetch`, XHR, `video.src`, `setAttribute`, DOM.
  При находке сверху появляется плашка «Поток найден» → кнопка ▶ открывает системный плеер.
  Центральная кнопка нижней панели открывает все найденные потоки и нативные серии.
- Нативный плеер получает Referer/Origin/UA/Cookie и умеет открыть поток в VLC/nPlayer,
  если не справился сам. В плеере есть выбор качества HLS (Авто / 1080p / 720p / …);
  для CVH дополнительно доступны фиксированные качества из API (1080p/720p/…),
  даже если `hlsUrl` оказался односегментным плейлистом. Стандартная кнопка закрытия
  iPad-плеера сохранена.
- **Память просмотра:** плеер запоминает серию, озвучку и таймкод. На странице тайтла
  появляется зелёная кнопка **▶ Продолжить 12:34**, а в списке серий — «Продолжить с …».
- **YummyAnime:** кнопка **▶ Серии** открывает нативный выбор серии и озвучки
  (два выпадающих списка) и запускает HLS напрямую через AVPlayer — без сломанного
  плеера CDNVideoHub.
- **AniLibria:** страницы сайта остаются рабочими за счёт блокировки несовместимых
  Next.js-скриптов (серверный HTML показывается без гидратации), а кнопка **▶ Серии**
  получает список озвучек/серий и HLS через API AniLibria/AKURO.
  Обложки AniLibria отдаются в WebP, который iOS 12 не умеет декодировать; на этих
  страницах автоматически подключается WebP-полифилл (webp-hero), который лениво
  перекодирует видимые картинки в JPEG/PNG и не тратит память на весь каталог.
- Блокировка рекламы: `WKContentRuleList` (сеть) + косметические правила (JS).
- Полифиллы для WebKit iOS 12 (Promise.finally, Object.fromEntries, flat, matchAll,
  IntersectionObserver, ResizeObserver и т.д.), чтобы современные сайты не падали.
- Попапы плеера (`window.open`/`target=_blank`) открываются в новой вкладке.

## Что не умеет (и не сможет)

- **Кинопоиск, Netflix, IVI, Wink — платный контент.** Он закрыт DRM (Widevine/FairPlay).
  На iOS 12 это не играет ни в одном браузере, включая свежий Safari. Страницы и трейлеры
  открываются, фильмы — нет. Обхода нет.
- Сайты, которым нужен MSE (MediaSource Extensions) на iPhone. В iOS 12 MSE на iPhone
  отсутствует физически. Если плеер отдаёт готовый `m3u8` — сработает нативный HLS,
  если крутит сегменты через MSE — нет.
- **VK / VK Video.** VK отдаёт современный бандл с `?.`/`??` и редиректит iOS 12 на
  `badbrowser.php`; даже с Chrome-UA приложение VK не парсится WebKit 12. Это ограничение
  движка, а не блокировщика. Для VK нужен либо свежий iOS, либо официальное приложение.
- Синтаксис JS новее ES2017 (`?.`, `??`, `\p{...}`) полифиллами не лечится: это ошибка
  парсинга. Если сайт на них — помогает только серверный HTML (как у AniLibria) или
  старая/мобильная версия.

## Сборка (Windows → GitHub Actions)

Локально на Windows iOS-приложение не собрать (нужен clang + SDK). Поэтому сборка в облаке:

1. Создай репозиторий на GitHub и запушь эту папку:
   ```bash
   git remote add origin https://github.com/USER/yumi-browser.git
   git push -u origin main
   ```
2. Открой **Actions → Build → Run workflow** (или просто сделай push).
3. Через 5–10 минут скачай артефакт **Yumi-packages**:
   - `Yumi-1.1.2.deb` — для установки через Cydia/Filza/dpkg;
   - `Yumi-unsigned.ipa` — для AppSync Unified / sideload.

## Установка

**Вариант 1 — .deb (рекомендуется, iOS 12 rootful: unc0ver / checkra1n):**
- открыть `.deb` в Filza → Install, или по SSH: `dpkg -i Yumi-1.1.2.deb`, затем `uicache -a`;
- приложение появится на рабочем столе как **Yumi**.

**Вариант 2 — .ipa:**
- нужен **AppSync Unified** (repo: cydia.akemi.ai) или AltStore/Sideloadly с подписью;
- открыть `.ipa` в Filza → Install, либо установить через AppSync.

## Как пользоваться

1. Запусти Yumi — на стартовой странице нажми **+ Добавить сайт** и добавь нужные
   адреса (например, `old.yummyani.me`). Сайты сохраняются и появляются карточками.
2. Открой `old.yummyani.me`, залогинься (cookies сохраняются).
3. На странице тайтла нажми красную кнопку **▶ Серии** справа внизу → выбери серию
   и озвучку в двух выпадающих списках. Видео откроется в системном плеере.
   Если ты уже смотрел, рядом появится зелёная **▶ Продолжить 12:34**.
4. Для остальных сайтов запусти плеер на странице серии. Через пару секунд сверху
   появится плашка **«Поток найден»** — нажми ▶. Откроется системный плеер с нужными
   заголовками (Referer страницы, cookies домена).
5. Все найденные потоки и нативные серии — по центральной кнопке нижней панели
   (иконка плеера). Там же «Продолжить: серия N · 12:34».
6. В плеере: качество — кнопкой **Авто ▾** справа сверху; закрытие — штатной кнопкой
   iPad-плеера.
7. Не играет?
   - меню → **Полная версия сайта**, перезагрузи страницу;
   - выключи блокировку рекламы в настройках (иногда режет плеер);
   - в плеере нажми **VLC** / **nPlayer**, если установлены;
   - проверь, что поток вообще HLS: сайты с MSE/DRM на iPhone не заиграют.
8. AniLibria: открой страницу тайтла (например, через поиск Яндекса) — сайт покажет
   серверную версию, а кнопка **▶ Серии** соберёт озвучки и запустит HLS.

## Настройки

- **Версия сайта** — мобильная/полная по умолчанию.
- **User-Agent** — iOS Safari 12, macOS Safari 16 или своя строка.
- **Поисковик** — Яндекс (по умолчанию), Bing или DuckDuckGo HTML.
- **Перехватывать потоки** — включён по умолчанию.
- **Автоматически играть HLS** — сразу открывать первый найденный HLS (по умолчанию выключено,
  чтобы не запускать рекламные вставки).
- **Блокировать рекламу** — сетевые правила WebKit + косметика.
- **Очистить кэш и cookies**, **Сбросить настройки**.
- **Инкогнито** — в меню браузера (не в настройках), чтобы не путать с обычными вкладками.

## Структура

```
Makefile                     Theos
control                      метаданные .deb
LaunchScreen.storyboard      компилируется в CI через ibtool
YumiBrowser/
  main.m                     AppDelegate
  BrowserViewController.*    вкладки, бары, меню, плашка потока
  YumiTab.*                  WKWebView на вкладку, навигация, cookies, перехват ссылок
  YumiBridge.*               JS → native
  YumiScripts.*              загрузка JS/HTML из бандла
  YumiSettings.*             NSUserDefaults
  YumiSiteStore.*            свои сайты на стартовой странице
  YumiResumeStore.*          память просмотра (серия/озвучка/таймкод)
  YumiYummyResolver.*        API YummyAnime + CDNVideoHub
  YummyEpisodesViewController.*  выбор серии/озвучки
  YumiAnilibriaResolver.*    API AniLibria/AKURO через страницу сайта
  YumiAdBlocker.*            WKContentRuleList (+ блок Next.js у AniLibria)
  YumiPlayer.*               AVPlayer + Referer/Cookie + VLC/nPlayer + качество
  TabsViewController.*       список вкладок
  SettingsViewController.*   настройки
  YumiIcons.*                иконки, нарисованные кодом
  Resources/
    Info.plist
    polyfills.js             шимы WebKit iOS 12
    hook.js                  перехват потоков + косметика
    home.html                стартовая страница (логотип + свои сайты)
    Icon-*.png               иконки (tools/generate-icons.py)
```

## Отладка

Логи приложения: `idevicesyslog | grep Yumi` (libimobiledevice) или в Xcode Devices.
Если сборка упала — смотри лог шага **Build** в Actions: чаще всего это несовместимость
Theos/SDK, лечится сменой `runs-on` (macos-14 → macos-13) и версии SDK.
